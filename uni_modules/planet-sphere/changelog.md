# Planet Sphere 更新日志

## [1.0.0] - 2025-06-17

### 🎉 首次发布

#### ✨ 新增功能
- **3D球面展示**：基于Three.js实现3D球面用户展示效果
- **跨平台支持**：完整支持H5、App、微信小程序三大平台
  - H5/App端：使用renderjs + Three.js实现
  - 微信小程序端：使用canvas + Three.js小程序版实现
- **多种显示模式**：
  - 用户头像图片显示
  - 用户姓名首字母显示
  - 纯色背景显示
- **丰富的交互功能**：
  - 拖拽旋转星球
  - 自动旋转（支持开关）
  - 点击用户头像交互
  - 旋转方向控制（左/右/自动）

#### 🎨 可定制选项
- **尺寸控制**：
  - 组件宽高自定义（width/height）
  - 头像大小调节（avatarSize: 30-100）
  - 文字大小控制（textSize: 12-50，userNameSize: 10-30）
- **速度调节**：
  - 拖拽旋转速度（rotateSpeed: 0.1-5.0）
  - 自动旋转速度（autoRotateSpeed: 0-2.0）
- **颜色定制**：
  - 48种预设用户颜色
  - 自定义用户颜色数组（userColors）
  - 选中高亮颜色（selectedColor）
  - 用户名颜色（userNameColor/selectedUserNameColor）
- **相机设置**：
  - 视野角度调节（cameraFov: 0-120°）
  - 相机距离控制（cameraDistance）

#### 🎯 事件系统
- **userClick事件**：用户点击时触发，返回用户对象
- **directionChange事件**：旋转方向改变时触发

#### ⚡ 性能优化
- **纹理资源管理**：相同头像共享纹理，减少内存占用
- **渲染优化**：针对不同平台采用最优渲染策略
- **事件防抖**：避免频繁操作导致性能问题
- **内存清理**：组件销毁时自动清理Three.js资源
- **触摸优化**：微信小程序端专门优化触摸事件处理

#### 🛠️ 技术特性
- **条件编译**：使用uni-app条件编译适配不同平台
- **组件分离**：
  - `planet-sphere.vue`：主入口组件
  - `planet-sphere-webandApp.vue`：H5/App专用组件
  - `planet-sphere-mp.vue`：微信小程序专用组件
- **Three.js集成**：
  - H5/App端使用标准Three.js
  - 微信小程序端使用Three.js小程序适配版
- **自定义控制器**：针对不同平台实现专用的交互控制器

#### 📱 平台兼容性
- ✅ **H5浏览器**：Chrome、Safari、Firefox、Edge
- ✅ **移动端App**：iOS、Android原生应用
- ✅ **微信小程序**：支持基础库2.9.0+
- ❌ **其他小程序**：暂不支持（支付宝、百度、字节跳动等）

#### 🎮 用户体验
- **流畅交互**：60fps流畅动画效果
- **响应式设计**：支持不同屏幕尺寸适配
- **用户反馈**：点击、拖拽等操作有即时视觉反馈
- **加载优化**：资源预加载，减少白屏时间
- **错误处理**：完善的错误捕获和用户提示

#### 📦 包含文件
- `components/planet-sphere/planet-sphere.vue` - 主组件文件
- `components/planet-sphere/planet-sphere-webandApp.vue` - H5/App版本
- `components/planet-sphere/planet-sphere-mp.vue` - 微信小程序版本
- `static/three.weapp.js` - Three.js微信小程序版本库
- `package.json` - 插件配置文件
- `readme.md` - 使用说明文档
- `changelog.md` - 版本更新日志

#### 🔧 配置支持
支持所有主要配置参数的响应式更新：
- 用户数据实时更新
- 显示模式动态切换
- 颜色主题即时变更
- 交互参数在线调节
- 相机视角实时调整

#### 📋 已知限制
1. 微信小程序端性能相对较弱，建议用户数量控制在100个以内
2. 其他小程序平台暂不支持，主要受限于Three.js兼容性
3. 头像图片需要支持跨域访问（H5端）
4. 微信小程序端建议使用网络图片而非本地图片

#### 🎯 使用场景
- 社交应用的好友/群成员展示
- 企业应用的团队成员展示
- 教育应用的班级学生展示
- 任何需要用户列表3D展示的场景
